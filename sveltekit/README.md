# SvelteKit

```sh
pnpm install
pnpm dev      # dev server
pnpm check    # svelte-check
pnpm lint     # biome
pnpm build
```

SvelteKit is configured through the `sveltekit()` plugin in `vite.config.ts`. `adapter-auto` is a placeholder; pick an [adapter](https://svelte.dev/docs/kit/adapters) for your deploy target.
